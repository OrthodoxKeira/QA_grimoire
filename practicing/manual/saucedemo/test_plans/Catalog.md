### 2. Цели тестирования

- Проверить корректность отображения товаров в каталоге (изображения, названия, цены).
- Проверить работу основных действий на странице каталога (добавление/удаление товара, счётчик корзины).
- Сравнить поведение разных типов пользователей (`standard_user`, `problem_user` и др.).
- Найти и задокументировать дефекты, связанные с UI и функциональностью каталога.

---

### 3. Объём тестирования (Scope)

#### ✅ В объёме (In Scope)

| Функциональность                              | Тип тестирования      |
|-----------------------------------------------|-----------------------|
| Отображение товаров в каталоге                | UI + Функциональное   |
| Изображения и названия товаров                | UI                    |
| Кнопки Add to cart / Remove                   | Функциональное        |
| Счётчик товаров в корзине                     | Функциональное        |
| Поведение разных пользователей                | Функциональное + UI   |
| Базовая авторизация (как предусловие)         | Функциональное        |

#### ❌ Вне объёма (Out of Scope)

- Полный процесс оформления заказа (checkout)
- Нагрузочное и performance-тестирование
- Кроссбраузерное тестирование (пока только один браузер)
- Мобильная версия
- API-тестирование
- Автоматизация

---

### 4. Подход к тестированию

| Тип тестирования     | Как проводим                          |
|----------------------|---------------------------------------|
| Функциональное       | По тест-кейсам и чек-листам           |
| UI / Usability       | Визуальная проверка + скриншоты       |
| Сравнительное        | Одинаковые сценарии на разных users   |
| Exploratory          | Свободное исследование каталога       |

Основные пользователи для проверки:
- `standard_user` — эталонное поведение
- `problem_user` — известные проблемы
- при необходимости: `performance_glitch_user`, `error_user`

---

### 5. Критерии входа и выхода

**Entry Criteria:**
- [ ] Сайт https://www.saucedemo.com доступен
- [ ] Известны тестовые учётки
- [ ] Написаны основные тест-кейсы и чек-лист
- [ ] Подготовлено окружение (браузер, разрешение)

**Exit Criteria:**
- [ ] Пройдены все тест-кейсы по каталогу
- [ ] Найденные дефекты оформлены в баг-репорты
- [ ] Есть скриншоты по критичным/мажорным багам
- [ ] Составлен краткий итог (что работает / что сломано)
