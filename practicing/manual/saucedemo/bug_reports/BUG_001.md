### Описание

#### Шаги для воспроизведения (Steps to Reproduce)

1. Открыть `https://www.saucedemo.com`
2. Ввести Username `problem_user`
3. Ввести Password `secret_sauce`
4. Нажать кнопку «Login»

#### Ожидаемый результат (Expected Result)

После редиректа на страницу каталога, в каждой карточке товара отображается изображение в соответствии с товаром.

#### Фактический результат (Actual Result)

Вместо изображений товаров отображается одно и то же изображение с псом. Вероятно плейсхолдер.
