### BUG-002: Кнопка «Remove» не убирает товар из корзины на странице каталога

| Поле              | Значение                                                          |
|--------------------|-------------------------------------------------------------------------|
| **ID**            | BUG-002                                                           |
| **Название**      | Кнопка «Remove» не убирает товар из корзины на странице каталога |
| **Модуль**        | Каталог товаров (Inventory)                                      |
| **Серьёзность**   | 🟡 Major *(функция работает некорректно, но есть обходной путь — убрать товар можно со страницы корзины)* |
| **Приоритет**     | 🟡 Средний                                                        |

|------------------|--------------------------------------------------|
| **Приложение** | SauceDemo                                    |

| **Устройство** | ПК                                            |
| **Окружение**  | Prod (публичный демо-сайт)                   |
| **URL**        | `https://www.saucedemo.com/inventory.html`   |

### Описание

#### Шаги для воспроизведения

1. Открыть `https://www.saucedemo.com`
2. Ввести Username `problem_user`
3. Ввести Password `secret_sauce`
4. Нажать кнопку «Login»
5. На странице каталога (`/inventory.html`) нажать кнопку «Add to cart» у любого товара
6. Кнопка меняется на «Remove»
7. Нажать кнопку «Remove»

#### Ожидаемый результат

После нажатия «Remove» товар убирается из корзины, счётчик корзины уменьшается, кнопка снова меняется на «Add to cart».

#### Фактический результат

Товар остаётся в корзине, счётчик корзины не меняется, кнопка не возвращается в состояние «Add to cart».
