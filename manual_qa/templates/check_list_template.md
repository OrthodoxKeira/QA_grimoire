# ✅ Шаблон чеклиста (Checklist)

## Что такое чеклист?

Чеклист — это **список проверок** без детальных шагов. Используется, когда проверка очевидна из формулировки, или когда нужно быстро охватить большую область.

**Когда использовать чеклист вместо тест-кейса:**
- Smoke / Sanity тестирование
- Регрессионное тестирование знакомой функциональности
- Исследовательское тестирование (exploration)
- Приёмочное тестирование (UAT)

## Советы

> **Формулируй проверку утвердительно:** не «Проверить кнопку», а «Кнопка «Купить» отображается и кликабельна».

> **Детализация зависит от опыта:** для новой функциональности пиши подробнее, для знакомой — можно кратко.

> **Группируй проверки** по разделам с заголовками `###` для больших чеклистов.
