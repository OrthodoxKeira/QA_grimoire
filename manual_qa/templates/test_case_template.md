# 📋 Шаблон тест-кейса (Test Case)

## Что такое тест-кейс?

Тест-кейс — это документ, описывающий **конкретную проверку** одной функции или поведения системы. Включает входные данные, шаги и ожидаемый результат.

---

## Шаблон

### Метаданные

| Поле            | Значение                          |
|-----------------|-------------------------------------|
| **ID**          | TC-[номер], например TC-001       |
| **Название**    | [Краткое описание что проверяем]  |
| **Модуль**      | [Раздел / функциональность]       |
| **Приоритет**   | 🔴 Высокий / 🟡 Средний / 🟢 Низкий |
| **Тип**         | Позитивный / Негативный / Граничный |
| **Автор**       | [Имя]                              |
| **Дата**        | [ГГГГ-ММ-ДД]                       |
| **Статус**      | Черновик / Активный / Устарел     |

---

### Предусловия (Preconditions)

> Что должно быть выполнено **до** начала теста?

- [ ] [Условие 1, например: пользователь авторизован]
- [ ] [Условие 2, например: в корзине есть 1 товар]

## Пример заполненного тест-кейса

### Метаданные

| Поле            | Значение                                      |
|-----------------|--------------------------------------------------|
| **ID**          | TC-012                                        |
| **Название**    | Авторизация с корректными email и паролем     |
| **Модуль**      | Авторизация                                   |
| **Приоритет**   | 🔴 Высокий                                    |
| **Тип**         | Позитивный                                    |
| **Автор**       | Анна Иванова                                  |
| **Дата**        | 2024-11-01                                    |
| **Статус**      | Активный                                      |

### Предусловия

- [ ] Пользователь зарегистрирован в системе
- [ ] Пользователь НЕ авторизован (открыта страница логина)

### Тестовые данные

| Параметр  | Значение             |
|-----------|-------------------------|
| Email     | test@example.com     |
| Пароль    | Qwerty123!            |

### Шаги выполнения

| № | Действие                                      | Ожидаемый результат                        |
|---|-----------------------------------------------|---------------------------------------------|
| 1 | Открыть страницу `/login`                     | Отображается форма входа                   |
| 2 | Ввести email `test@example.com`               | Email введён в поле                        |
| 3 | Ввести пароль `Qwerty123!`                    | Пароль скрыт точками                       |
| 4 | Нажать кнопку «Войти»                         | Появляется спиннер загрузки                |
| 5 | Дождаться завершения загрузки                 | Редирект на `/dashboard`, имя в шапке      |

### Постусловия

- Пользователь авторизован и видит личный кабинет
- В cookies/localStorage записан токен сессии

---

## Советы

> **Один тест-кейс = одна проверка.** Если хочется проверить две вещи — сделай два кейса.

> **Шаги должны быть атомарными** — каждый шаг один клик или одно действие.

> **Ожидаемый результат** пиши конкретно: не «всё ОК», а «появляется сообщение "Успешно"».
