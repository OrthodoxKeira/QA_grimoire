# QA Grimoire

Личная база знаний и портфолио по тестированию ПО.  
Веду её в процессе обучения: теория → практика → разбор.

## Skills

**Manual QA**
- Тест-дизайн, чек-листы, тест-кейсы, баг-репорты
- Функциональное, UI, smoke, регрессионное тестирование
- Работа с разными типами пользователей и дефект-ориентированное тестирование

**Tools**
- Browser DevTools
- Postman (базовый уровень)
- SQL (SELECT, JOIN, WHERE, UPDATE, DELETE)
- Jira / баг-трекеры (на уровне оформления отчётов)

**Additional**
- Python (веб)
- Интерес к Game QA / тестированию игр

## Структура репозитория

- `theory/` — конспекты по теории тестирования
- `api_testing/` — теория и практика по API
- `manual_qa/templates/` — шаблоны документов
- `practicing/` — практические кейсы
  - [SauceDemo](./practicing/manual/saucedemo/) — полный цикл: тест-план, чек-листы, тест-кейсы, баг-репорты

## Подход к обучению

1. Формирую свою гипотезу
2. Изучаю теорию
3. Практикую на реальных/демо-сайтах
4. Разбираю ошибки и улучшаю артефакты

## Статус

Репозиторий активно наполняется.  
Сейчас основной акцент — на качестве ручного тестирования и оформлении артефактов.
