# QA Grimoire

Личная база знаний по QA. Веду её, пока учусь тестированию — конспекты теории, шаблоны документов и практика на тестовых сайтах.

## Структура

- `theory/` — конспекты по теории тестирования 
- `api_testing/` — теория по API и заметки по практике в Postman
- `manual_qa/templates/` — шаблоны документов
- `practicing/` — документы, написанные по этим шаблонам на тестовых сайтах

## Как это устроено

Тема разбирается в таком порядке: своя гипотеза —> теория —> практика —> разбор и правки.

## Статус

Репозиторий пополняется по ходу обучения.
