# JSON и структура ответа API

## 1. JSON 

JSON - текстовый формат для передачи структурированных данных. 



## 2. типы данных в JSON

JSON - поддерживает всего 6 типов данных

* String - "Anna" - всегда в двойных кавычках
* Number - 42, 3.14 - целое или дробное
* Boolean - true, false 
* Array - [] - список
* Object - {} - словарь
* null - null - None

## 3. Структура типичного ответа API

```{
  "status": "success",
  "data": {
    "id": 42,
    "name": "Иван Петров",
    "email": "ivan@example.com"
  },
  "meta": {
    "requestId": "abc-123",
    "timestamp": "2026-07-05T10:00:00Z"
  }
}
```
*data* - полезная нагрузка, то, что запрашивали
*meta* - служебная информация: время запроса, ID для отладки, пагинация

## 4. Структура ответа с ошибкой

```{
  "status": "error",
  "error": {
    "code": "VALIDATION_ERROR",
    "message": "Email имеет неверный формат",
    "field": "email"
  }
}
```
Тело ответа должно возвращать осмысленный текст ошибки, иначе баг

## 5. Что проверяем в теле

* Наличие всех ожидаемых полей (В соответствии с документацией)
* Правильные типы данных
* Отсутствие лишних\чувствительных полей
* Корректность значений
* Пустые\null значения там, где не должно быть
* Соответствие данных запросу
